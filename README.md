## 🤖 AI / RAG Engineering

One of my current areas of focus is building AI systems that work with **real data rather than isolated demonstrations**.

### What I work with

* 🔎 Retrieval-Augmented Generation (RAG)
* 🗂️ Vector Search
* 🔀 Hybrid Search
* 🧠 Multi-Agent AI workflows
* 🔌 LLM API integrations
* 📚 Knowledge-base systems
* ⚙️ AI-powered automation
* 💬 AI Chat & Customer Support systems
* 🛡️ Human-in-the-loop workflows

### My approach

AI is not perfect — and production systems shouldn't pretend that it is.

I design AI systems around principles such as:

> **Accuracy first.**
>
> **Use trusted data whenever possible.**
>
> **If the system doesn't know, it should be able to say "I don't know."**
>
> **Keep humans in the loop when decisions matter.**

The goal is to make AI useful while keeping the system transparent, reliable, and maintainable.

## 🧠 Engineering Philosophy

```text
A good system isn't the one with the most features.

It's the one that:
    → solves the actual problem
    → uses the right architecture
    → protects the data
    → handles failure gracefully
    → is understandable by humans
    → can be maintained after deployment
```

I believe software engineering is not just about writing code.

It's about understanding **what should be built, why it should exist, and how it should behave when things go wrong.**
